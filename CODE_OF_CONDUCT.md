# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Please
read the full text there. It is the standard that applies, and this page only summarises it.

In short: be respectful and constructive, assume good intent, keep discussion on the work, and do not harass, threaten or publish
other people's private information. Disagreement about design is welcome when it is about the design.

## Reporting

To report a concern about behaviour in this project, contact the maintainer privately through GitHub at
[acarmisc](https://github.com/acarmisc), or use GitHub's private reporting for the repository. Do not post the concern in a public
issue or pull request. Reports are read in confidence. The maintainers respond as the Contributor Covenant's enforcement guidelines
describe.

Security problems are not conduct reports; follow [SECURITY.md](SECURITY.md) for those.
